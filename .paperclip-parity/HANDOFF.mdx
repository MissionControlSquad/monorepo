## 1. What this repo is (architecture)

- **Monorepo**: Turborepo + npm workspaces. Next.js 15.3 App Router + React 19, Prisma (split schema
  `packages/database/prisma/schema/*.prisma`), Pothos code-first GraphQL + graphql-yoga, urql client,
  Postgres, vitest.
- Packages: `@agentcenter/{utils,database,graphql-server,graphql-client,types,hooks,config}`,
  `@agentcenter/runner` (standalone daemon), and the app at `apps/web`.
- **`@buildbase/sdk` is the tenancy boundary.** Human auth, billing, orgs, workspaces, RBAC/roles are
  ALL SDK-owned — **never rebuild them**. Your code only *consumes* `workspaceId` scoping + the admin
  check. **MCP is also buildbase-provided → do NOT build MCP** (it's advisory-only in `06-plugins-mcp.mdx`).
- Auth in the app: `resolveAgent(request)` (Bearer `mc_` key, REST) and `requireRole(ctx, "admin"|"member")`
  (workspace JWT cookie, GraphQL). Feature flags: `packages/utils/src/feature-flag-keys.ts`
  (`FLAG_KEYS`, all new work default **off**).

## 3. Verification loop (run these; keep them green)

From the **repo root** unless noted. Clear stale Next types first if typecheck complains.

```bash
# typecheck (all packages) — expect "12 successful"
rm -rf apps/web/.next/types && npx turbo run typecheck

# apply the DB schema to YOUR test DB (edit apps/web/.env.test DATABASE_URL first)
cd packages/database && npx prisma generate \
  && npx dotenv -e ../../apps/web/.env.test -- npx prisma db push --accept-data-loss --skip-generate

# run a test file (from apps/web). NOTE the --hookTimeout: a global beforeAll in tests/setup.ts
# reads flags from the DB and flakily times out at the default 10s under load — 40s makes it reliable.
cd apps/web && DISABLE_FLAG_CACHE=1 npx dotenv -e .env.test -- \
  npx vitest run tests/integration/<file>.test.ts --hookTimeout=40000

# build the web app — expect "Compiled successfully"
rm -rf apps/web/.next && npx turbo run build --filter=@agentcenter/web
```

Prisma models live in `packages/database/prisma/schema/*.prisma`; write a matching migration under
`packages/database/prisma/migrations/<timestamp>_<name>/migration.sql` (the CI/deploy path uses
`prisma migrate`, but tests use `db push`, so raw partial-unique indexes in a migration are NOT present in
the test DB — enforce those in app code too, as the Environment code does).

## 4. Conventions (match these — the reviewer will)

- **Every new surface is feature-flag-gated** (add to `FLAG_KEYS` + `FLAG_DEFAULTS: false`), **workspace-
  scoped**, and **admin-gated for mutations** (`requireRole(ctx, "admin")`), member for reads.
- **Secrets never leave the server.** Store config secrets as `{secretRef:{name}}` vault pointers; return
  masked values only. SSH keys encrypted at rest. Scrub secret values from any streamed/logged output.
- Shared GraphQL queries/mutations go in **`@agentcenter/graphql-client`** (so web + mobile + desktop get
  them free), re-exported through `apps/web/src/lib/graphql/{queries,mutations}`.
- Build vertical slices: schema → service → GraphQL → shared client → UI → tests, and **verify after each**
  (typecheck + the slice's test + build). Prefer pure, unit-testable resolvers in `@agentcenter/utils`.
- **Commit only when asked; push only when asked.** End commit messages with:
  `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`
- After finishing an item, **update `.paperclip-parity/INDEX.mdx`** (check it off with the commit hash +
  a one-line summary) — that file IS the handoff memory.
