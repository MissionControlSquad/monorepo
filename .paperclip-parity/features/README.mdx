# Parity feature tree

One file per **everything** — every Paperclip service, every UI surface, and every
cross-cutting feature — so each item is independently linkable and reviewable.
Source of truth for classification is [`../SERVICE-AUDIT.mdx`](../SERVICE-AUDIT.mdx)
(the 177-row line-item table) and [`../CODEBASE-COVERAGE.mdx`](../CODEBASE-COVERAGE.mdx)
(routes/CLI/middleware/components/hooks/apps). Priorities defined in
[`../PRIORITIES.mdx`](../PRIORITIES.mdx).
