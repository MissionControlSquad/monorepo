# Agents — lifecycle & identity · P0 · ✅ Present

**What it is:** create/hire agents, activate/deactivate, vacation, sleep/wake, heartbeat, identity
sync, org-chart reporting, personal work queue, action log, and the agent-company container.

**Present in our monorepo (verified):**
- Create/hire: REST `app/api/agents/create` + `batch-create`; hire via approval
  `mutations/approvals.ts:requestAgentHire`; wizard `views/NewAgentWizard.tsx`.
- Activation/vacation/sleep/wake: `mutations/agents.ts` (`setAgentActivation`, `setAgentVacation`,
  `wakeAgent`, `sleepAgent`) — guards last active Squad Lead.
- Status + history: `AgentStatus`/`DetailedStatus`/`StatusHistory` (`agent.prisma`),
  `subscriptions/agentStatusChanged.ts`, `components/agent/StatusHistoryTimeline.tsx`.
- Heartbeat + auto-sleep: `agentHeartbeat`, `agent.prisma:lastHeartbeat`, cron `auto-sleep` (5-min stale).
- Identity/config: `syncAgentIdentity`, `configVersion`, `/api/agents/me/config-bundle`.
- Org chart: `agent.reportsToAgentId` self-FK, `services/org-chart.ts` (cycle guard),
  `queries: orgChart/orgChartSvg/agentOrgChainHealth`, route `/org-chart`.
- Personal queue + actions: `AgentQueueItem`, `AgentAction`, `subscriptions/agentActionLogged.ts`,
  profile cards (queue, runs, memory, salary).
- Companies: `agent-company.prisma`, `services/agent-companies.ts`, `views/AgentCompaniesPage.tsx`.

**Gaps / pending:** None material. (Agent *execution* is a separate feature — see P1 sandbox.)

**What's required:** Nothing — fully wired schema→service→GraphQL→client→UI.

**Priority rationale:** Without agents there is no product. Foundational.

**Depends on:** buildbase for human identity; nothing else.
