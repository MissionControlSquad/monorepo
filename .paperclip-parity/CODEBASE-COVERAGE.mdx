## Additional gaps found by broadening (not in the first audit)

### 1. CLI — `paperclipai` (a full user/operator CLI) — mostly MISSING · P2/P3
Paperclip's `cli/` is the primary human entrypoint ("orchestrate AI agent teams to run a business").
Commands: `run` · `doctor` · `db-backup` · `configure` · `env` / `env-lab` · `onboard` ·
`auth-bootstrap-ceo` · `allowed-hostname` · `pipelines` · `routines` · **`worktree` / `worktree-merge-history`**.
Checks (`doctor`): agent-jwt-secret, config, database, deployment-auth, llm, log, port, secrets.

**Monorepo:** only `@agentcenter/runner` (the agent-run daemon) — the equivalent of `run`. **Missing:**
`doctor`+checks, `db-backup`, `configure`/`env`/`onboard`, and — notably — **`worktree` management**, which
is exactly the **execution-workspace realization** logic (P1 #58/175). So the worktree gap shows up twice:
the sandbox seam doesn't realize worktree strategies (P1-execution-workspaces) **and** there's no CLI
worktree tool. → expands the P3 operator-CLI item; the worktree part is P1.

### 2. Middleware — SSRF guard + log redaction — MISSING · P1
Paperclip `server/src/middleware/` has **`private-hostname-guard.ts`** (SSRF — blocks private hostnames on
outbound) and **`http-log-redaction.ts`** (structured log redaction) as first-class middleware. This
**confirms** the second-pass P1 `remote-http-endpoint-guard` finding (it's wired as middleware) and the
`log-redaction` partial. Also present in Paperclip: `board-mutation-guard`, `http-log-policy`,
`api-compression` (minor).

### 3. Evals — MISSING · P2/P3
Paperclip ships `evals/` (11 files) — an agent/skill/memory eval harness. The monorepo has **no evals dir**
(confirms memory GAP-H + no general eval suite). Buildable-now (harness), but real evals need agent execution.

### 4. Realtime WebSockets — Partial · P1 (infra-gated)
Paperclip `realtime/`: `environment-custom-image-terminal-ws.ts` (terminal PTY WS — matches the monorepo's
deferred `terminals/`) and `live-events-ws.ts` (a general live-events socket — monorepo uses the
live-gateway WS + GraphQL subscriptions instead). No new feature, just confirms the terminals/live-gateway
infra gate.

### 5. UI component depth — Partial · P2
411 Paperclip components vs 174 monorepo (~40%). This is the "thin pages" observation quantified: the
monorepo has route parity but each page is shallower (Paperclip's IssueDetail/Secrets/CompanySkills are
100–200KB single pages). Not missing *features* — missing *depth*. Covered qualitatively in `features/P3-ui-polish.mdx`.
