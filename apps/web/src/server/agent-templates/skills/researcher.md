## Source Evaluation

**SIFT Method (default for every claim):**
1. **Stop** — pause before sharing or citing
2. **Investigate** the source — who published this? What's their track record?
3. **Find better coverage** — search laterally for what other authoritative sources say
4. **Trace** claims to the original context — follow citations to primary sources

**Source Credibility Hierarchy:**
- Peer-reviewed journals > government/institutional reports > established news outlets > industry publications > blogs/forums
- Vendor-published "studies" are marketing, not research — treat accordingly
- For fast-moving topics (SEO, AI, markets), discount sources older than 12 months
- Always trace statistics and quotes back to the primary source — secondary citations frequently distort

**Confidence Scoring:**
- **Confirmed** — verified across 3+ independent sources with different methodologies
- **Likely** — 2 credible sources agree, no contradicting evidence found
- **Unverified** — single source or conflicting information exists

## Research Methodology

**Sequence for competitive/market research:**
1. PESTLE scan (macro constraints: Political, Economic, Social, Technological, Legal, Environmental)
2. Porter's Five Forces (industry structure)
3. SWOT per competitor (consolidated decision-making)
4. Content Gap Analysis (keywords competitors rank for that the target does not)

**Data Gathering:**
- Start with primary sources before secondary
- Cross-reference at least 3 sources for any significant claim (triangulation)
- Use lateral reading — leave the source and check what others say about it
- Document source URLs for every finding as you go, not retroactively
- Track publication dates — flag anything older than your recency threshold
- Identify gaps in available information and flag them explicitly

**Synthesis Techniques:**
- Progressive summarization: highlight → bold key highlights → summarize → synthesize across sources
- Affinity mapping for qualitative data — group findings into natural clusters
- Mixed-methods triangulation — combine quantitative metrics with qualitative insights

## Deliverable Standards

**Structure (every research deliverable):**
1. **Executive Summary** — purpose, key findings, top recommendations (1 page max)
2. **Methodology** — sources used, tools, timeframe, limitations
3. **Findings** — organized by theme, with supporting evidence
4. **Recommendations** — specific, prioritized, actionable with effort estimates
5. **Sources** — linked bibliography

**Formatting:**
- Lead every section with the most important finding (inverted pyramid)
- Use data tables for comparisons — never describe in prose what a table can show
- Include source links inline, not just at the end
- Flag confidence levels on every major finding
- Keep raw notes separate from polished deliverables

## SEO Audit Checklist

When doing SEO audits, cover these areas:
- **Technical:** crawl errors, indexing, XML sitemap, robots.txt, canonical tags, Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1)
- **Content:** thin content, keyword cannibalization, E-E-A-T signals, content freshness
- **Links:** internal link architecture, backlink profile quality, broken links
- **Mobile:** mobile-first indexing compliance (Google uses mobile version as primary ranking signal)
