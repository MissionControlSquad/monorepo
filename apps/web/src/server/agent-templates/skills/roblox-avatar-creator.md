```
Classic Clothing:
  Shirt/Pants:  585×559 px PNG, RGB only (no alpha channel for shirts/pants)

Accessories (Legacy):
  Max tris:     ~2000 (hats), ~4000 (hair)

Layered Clothing:
  Cage meshes:  InnerCage + OuterCage required

  Head, Torso, LeftArm, RightArm, LeftLeg, RightLeg
  Must match R15 attachment point spec exactly
```

### Layered Clothing Rig in Blender (Export Pipeline)

```python
# blender_lc_export.py — Pre-export validation script
import bpy

def validate_lc_mesh(obj_name: str) -> list[str]:
    """Validate a layered clothing mesh before Roblox export."""
    errors = []
    obj = bpy.data.objects.get(obj_name)
    if not obj:
        return [f"Object '{obj_name}' not found"]

    me = obj.data

    # Check for required cages
    inner = bpy.data.objects.get(obj_name + "_InnerCage")
    outer = bpy.data.objects.get(obj_name + "_OuterCage")
    if not inner:
        errors.append("Missing InnerCage mesh")
    if not outer:
        errors.append("Missing OuterCage mesh")

    # Check armature
    armature_mod = next(
        (m for m in obj.modifiers if m.type == 'ARMATURE'), None
    )
    if not armature_mod:
        errors.append("No armature modifier found")

    # Check UV map exists
    if not me.uv_layers:
        errors.append("No UV map on clothing mesh")

    # Check texture
    for mat in me.materials:
        if mat and mat.use_nodes:
            has_tex = any(
                n.type == 'TEX_IMAGE' for n in mat.node_tree.nodes
            )
            if not has_tex:
                errors.append(f"Material '{mat.name}' has no image texture")

    # Poly count
    if len(me.polygons) > 5000:
        errors.append(f"Poly count {len(me.polygons)} exceeds 5000 limit")

    return errors

# Run validation
errs = validate_lc_mesh("LC_Hoodie")
if errs:
    for e in errs:
        print(f"[ERROR] {e}")
else:
    print("Mesh passes validation — ready for .fbx export")
```

### HumanoidDescription API

```lua
-- avatar_customizer.lua (LocalScript)
local Players = game:GetService("Players")
local player = Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid") :: Humanoid

-- Build a HumanoidDescription programmatically
local function applyCustomAvatar(
    bodyColorPreset: string,
    hatId: number,
    shirtId: number,
    pantsId: number
): ()
    local desc = humanoid:GetAppliedDescription()

    -- Body colors
    if bodyColorPreset == "classic" then
        desc.HeadColor    = BrickColor.new("Light orange")
        desc.TorsoColor   = BrickColor.new("Light orange")
        desc.LeftArmColor = BrickColor.new("Light orange")
        desc.RightArmColor= BrickColor.new("Light orange")
        desc.LeftLegColor = BrickColor.new("Medium blue")
        desc.RightLegColor= BrickColor.new("Medium blue")
    end

    -- Clothing
    desc.Shirt = shirtId
    desc.Pants = pantsId

    -- Accessories: comma-separated asset IDs
    local currentAccs = desc.HatAccessory
    if currentAccs == "" then
        desc.HatAccessory = tostring(hatId)
    else
        desc.HatAccessory = currentAccs .. "," .. tostring(hatId)
    end

    -- Apply (server-side via RemoteEvent for persistence)
    humanoid:ApplyDescription(desc)
end

-- Example: apply a preset outfit
applyCustomAvatar("classic", 1365767, 11884330786, 11884334668)
```

### In-Experience Avatar Editor (Server-Side Validation)

```lua
-- avatar_editor_server.lua (Script in ServerScriptService)
local Players        = game:GetService("Players")
local AvatarEditorService = game:GetService("AvatarEditorService")

local ALLOWED_ITEM_TYPES = {
    Enum.AvatarItemType.Asset,
}

local saveAvatarRemote = game.ReplicatedStorage.Remotes:WaitForChild("SaveAvatar")

saveAvatarRemote.OnServerEvent:Connect(function(
    player: Player,
    description: HumanoidDescription
)
    -- Validate the request comes from the right player
    if not player.Character then return end
    local humanoid = player.Character:FindFirstChildOfClass("Humanoid")
    if not humanoid then return end

    -- Verify items belong to the player or are free
    local success, result = pcall(function()
        return AvatarEditorService:ValidateOutfit(description)
    end)

    if not success or not result then
        warn(player.Name .. " submitted invalid avatar description")
        return
    end

    humanoid:ApplyDescription(description)

    -- Persist to DataStore
    local DataStoreService = game:GetService("DataStoreService")
    local avatarStore = DataStoreService:GetDataStore("PlayerAvatars")
    local encoded = encodeDescription(description) -- custom serializer
    pcall(avatarStore.SetAsync, avatarStore, tostring(player.UserId), encoded)
end)
```

### Clothing Template UV Reference

```
Roblox Shirt Template (585×559):
  Head front/back:   wraps around the neck area
  Torso front:       center rectangle
  Torso back:        mirrored section
  Left/Right Arm:    side columns

```

### Texture Optimization Guidelines

```
Mobile tier:     Max 256×256 per asset texture
Mid tier:        512×512 acceptable
Desktop/Premium: Up to 1024×1024 for detailed accessories

File format:     PNG with alpha for accessories
                 PNG without alpha for shirts/pants (platform ignores it)
Compression:     Roblox auto-converts to DXT; design with this in mind
Color profile:   sRGB — avoid AdobeRGB/ProPhoto, colors will shift
```

## Best Practices

- **Always use Roblox's official avatar rig** when caging layered clothing — third-party rigs cause deformation errors on upload.
- **Test on multiple body types** before publishing — R15 Normal, Slender, and Rthro proportions deform cages differently.
- **Keep texture atlases clean** — pack multiple accessories into one atlas to reduce draw calls in dense servers.
- **Use `HumanoidDescription` instead of direct part manipulation** — it's the correct API for avatar changes and works with avatar auto-scaling.
- **Preview in Studio before uploading** — the Upload to Roblox pipeline doesn't catch all cage issues; test with `InsertService:LoadAsset()`.
- **Version your UGC items** — keep Blender source files with version suffixes; Roblox doesn't allow re-uploading a fixed mesh to the same asset ID.
- **Follow community guidelines strictly** — UGC items are moderated; study the Creator guidelines to avoid rejections.

## Common Pitfalls

- **Flipped cage normals**: InnerCage normals must face inward (toward the body) and OuterCage normals must face outward. Wrong normals cause inside-out clipping.
- **Attachment point mismatch**: Accessories attached via `AttachmentPoint` must match the exact name and transform of R15 attachment points — even 0.01 stud offset is visible.
- **Texture bleed at seams**: Classic clothing textures bleed if UV islands are placed too close to each other — maintain a 2px buffer between UV islands.
- **`ApplyDescription` on client only**: Calling `humanoid:ApplyDescription()` from a LocalScript applies changes locally but not to other players. Always confirm via server.
- **Missing LOD on layered clothing**: Layered clothing without proper LODs causes significant performance drops in servers with many players — ensure the platform generates LODs by following mesh guidelines.
- **HatAccessory ID list corruption**: The `HatAccessory` field is a comma-separated string — accidentally appending duplicates or invalid IDs breaks the entire accessory list silently.

## Success Metrics

- Clothing textures show no visible seams or UV bleeding in-game
